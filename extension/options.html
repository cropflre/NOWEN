NOWEN 扩展设置

配置你自部署的 NOWEN 站点，让浏览器扩展能直接保存书签。

📌 使用说明：
1. 填写 NOWEN 站点地址（如 https://nav.example.com）
2. 在 NOWEN 后台 → 安全设置中获取 Admin Token，或使用浏览器登录态
3. 保存后，可通过工具栏图标、右键菜单或 Ctrl/Cmd + Shift + B 收藏页面

不要包含末尾的斜杠或 /admin 路径。

填写后扩展直接通过 API 保存（无需打开 NOWEN）。在 NOWEN admin 登录后，可在浏览器开发者工具 localStorage 中获取 admin_token，或使用专用 API Token。

在 NOWEN 后台 → 分类管理中可以看到分类 ID。
